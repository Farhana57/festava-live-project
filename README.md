# Festava Live - Event Management System

Festava Live is a modern, responsive festival and event management website. This project showcases a full-stack implementation featuring a dynamic frontend and a robust backend.

## 🚀 Features
* **Responsive Design:** Fully compatible with Mobile, Tablet, and Desktop using Bootstrap.
* **Event Sections:** Dedicated sections for Line-up, Schedule, and Pricing.
* **Ticket Booking:** Interactive form for users to book their tickets.
* **Contact Form:** Functional contact section for user inquiries.
* **Backend Integration:** Powered by Node.js and MongoDB for data management.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Version Control:** Git & GitHub

## 📂 Project Structure
* `/public` - Static assets (Images, CSS, JS)
* `/server` - Backend logic and API routes
* `index.html` - Main landing page

## 🔧 Installation
1. Clone the repository:
   `git clone https://github.com/Farhana57/festava-live-project.git`
2. Install dependencies:
   `npm install`
3. Run the server:
   `node server.js`
